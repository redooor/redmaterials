Typography

Redmaterials sets Roboto as the document and component font, keeps Bootstrap's heading scale, and leaves code and blockquote typography to Bootstrap with a small Material adjustment. No JavaScript is required for any of it.

Compared with stock Bootstrap. Bootstrap alone renders its system font stack at 16px; Redmaterials renders Roboto at 14px with a 1.4 line height, so the same text looks slightly smaller with Material's letterforms. The heading scale itself is Bootstrap's in both cases.

Roboto and body text

Load the Roboto stylesheet before Redmaterials' stylesheet; the font is not bundled with the theme.

scss/scaffolding.scss sets the body to "Roboto", 'Helvetica Neue', Helvetica, Arial, sans-serif at 400 weight, 14px, line height 1.4, colour var(--rdm-text), .1px letter spacing and antialiased smoothing. scss/_bootstrap5-theme.scss maps the same stack to --bs-body-font-family, so Bootstrap components inherit Roboto too. scss/type.scss contains only two rules: links use var(--bs-link-color) and .blockquote-footer uses var(--rdm-text-secondary).

Body copy

Body text renders at the 14px Roboto base; .lead, .small, mark, strong and em keep Bootstrap's styles.

A lead paragraph introduces a section with slightly larger, lighter text.

Regular body copy shows the 14px Roboto base and the 1.4 line height. It also shows bold text, italic text, highlighted text and a default link inside a paragraph.

Small text uses Bootstrap's .small size on top of the same Roboto stack.

Headings

Redmaterials does not redefine the heading scale, so Bootstrap 5.3's responsive h1–h6, heading classes and display headings render unchanged on top of Roboto.

Links

Links use the brand primary through var(--bs-link-color), and Bootstrap's contextual link utilities (.link-primary … .link-danger) are restyled through the --rdm-text-* tokens so they stay readable in dark mode.

Default link uses the theme's link colour and hover colour.

Body-emphasis link is the link style used in this documentation's prose.

Primary link, secondary link, success link, info link, warning link and danger link use the contextual link tokens.

Code and keyboard

scss/code.scss removes the border from pre and gives it a 2px radius; inline code, kbd and samp keep Bootstrap's styling.

Use var(--rdm-text) for body text, press Ctrl + C to copy, and read program output as docs built.

@use "redmaterials";

.card {
    border-radius: 2px;
}
$ npm run build:docs:html

Blockquotes

Bootstrap's .blockquote is unchanged; Redmaterials sets .blockquote-footer to var(--rdm-text-secondary) so the attribution stays readable in dark mode, and a .well blockquote uses var(--rdm-blockquote-border) for its border.
