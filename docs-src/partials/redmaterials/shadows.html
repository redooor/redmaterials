Shadows

scss/shadows.scss adds six depth classes, .shadow-depth-0 through .shadow-depth-5: depth 0 removes the shadow and depths 1 to 5 read the matching --rdm-shadow-depth-* token. The tokens follow data-bs-theme, so no data attribute or JavaScript is needed on the element.

Dark-mode note. The shadows deepen in dark mode and gain a faint inset top highlight, following Material's elevated dark surfaces; the same class therefore looks stronger on a dark page than on a light one.

Bootstrap vs Redmaterials. Bootstrap only ships .shadow-none, .shadow-sm, .shadow and .shadow-lg, so in Bootstrap mode all six depth classes are absent and the boxes below render flat.
