List group

Redmaterials keeps Bootstrap's list-group markup and adjusts the Material look: roomier .list-group-item padding, square first and last corners, a Material blue active item and a .list-group-item-heading helper for custom rows. No data attribute or JavaScript is required.

Compared with stock Bootstrap. Stock Bootstrap uses tighter padding, rounded outer corners and a #0d6efd active fill; Redmaterials uses roomier .list-group-item padding, square first and last corners and a Material blue active item. The .list-group-item-heading spacing is Redmaterials-only; the list, active, action and disabled classes are Bootstrap 5.

Action states

Use links or buttons with .list-group-item-action for rows that respond to hover and focus; add .active for the current row and disabled or .disabled for an unavailable one.

Custom content with a heading

Put .list-group-item-heading on a heading inside a custom .list-group-item to get a half-em gap below it; pair it with a paragraph and any Bootstrap utility.
