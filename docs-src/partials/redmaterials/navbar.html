Navbar

Redmaterials keeps Bootstrap's navbar markup and adds the Material depth shadow, a CSS-drawn breadcrumb separator and the legacy .navbar-toggle helper. Colour a navbar with a palette .bg-{colour} utility and set data-bs-theme="dark" on the navbar for dark fills so its links, brand and toggler turn white. Do not use the removed .navbar-{colour}, .navbar-dark or .navbar-light classes. The collapse and dropdown need Bootstrap's bundle JavaScript.

Compared with stock Bootstrap. Stock Bootstrap's navbar has no Redmaterials shadow, no breadcrumb separators and no styling for .navbar-toggle; Redmaterials adds the Material depth shadow, the CSS-drawn breadcrumb separators and the .navbar-toggle helper. The palette .bg-{colour} fills are absent as well, because those utilities are Redmaterials-only. All collapse, dropdown and data-bs-* markup is Bootstrap 5.

Breadcrumb navbar

Add .navbar-breadcrumb to a .navbar-nav list; Redmaterials draws the chevron separators in CSS, so no icon font or Font Awesome is needed. The separators are hidden below 768px.

Palette colours

Use a palette .bg-{colour} utility on the navbar and select its colour mode with data-bs-theme: dark fills use data-bs-theme="dark" for white links, while the very light yellow and lime fills use data-bs-theme="light" so their labels stay dark.

The navbar-toggle helper

.navbar-toggle is a legacy Redmaterials helper kept for plain buttons that act as a navbar toggler: it removes the margin, padding, border, radius and background and sets a pointer cursor. It does not add behaviour, so pair it with Bootstrap's data-bs-toggle="collapse" (as below) or your own handler and give the button an accessible name.

Legacy colour aliases

Documented as code only. .navbar-light and .navbar-dark are kept in scss/navbar.scss for backwards compatibility, but they are not used in the live examples above: Bootstrap 5.3 replaced them with data-bs-theme. .navbar-light forces dark text on a light bar, while .navbar-dark only fixes the search field colours inside a dark bar.
