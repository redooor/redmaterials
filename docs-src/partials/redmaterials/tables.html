Tables

scss/tables.scss builds on Bootstrap 5.3's variable-driven .table: transparent base, theme-aware borders, token-based striped, hover and active rows, and roomier 1.6rem cell padding. The palette tables add a .table-{colour} class that tints the striped and hover rows and keeps the theme's table text colour, so they stay readable in light and dark mode. No data attribute or JavaScript is needed.

The table palette covers 17 of the 19 Material colours. There is no .table-grey or .table-blue-grey: scss/tables.scss stops at .table-brown, so those two classes are not documented as if they existed.

Compared with stock Bootstrap. Stock Bootstrap has no .table-red … .table-brown palette classes, so its stripes and hover use its own colours, and its cell padding is tighter than the 1.6rem Redmaterials uses; Redmaterials adds the palette classes that tint the striped and hover rows. .table-sm is Bootstrap 5; .table-condensed, .table-no-border and .table-responsive-vertical are Redmaterials additions.

Striped and hover

Bootstrap's .table-striped, .table-hover and .table-active are restyled from theme tokens, with a 0.3s transition on the cells; the striped tint alternates rows and the hover tint follows the pointer, while .table-active marks a row persistently.

No border

.table-no-border removes every cell border while keeping the row padding, stripes and hover tint; the table's outer border is not part of .table, so the class only affects the cells.

Responsive vertical

.table-responsive-vertical keeps a normal table above 768px and, at 768px and below, hides the header and footer, turns every row into a bordered block and every cell into a right-aligned line. Add data-title to each td: the stylesheet prints it with ::before as the line's label. Narrow the browser to see the stacked layout.
