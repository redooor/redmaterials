Utilities

Redmaterials extends Bootstrap's colour utilities with the 19-colour Material palette and a neutral default and muted variant for backgrounds, text and borders. No data attribute or JavaScript is required: the utility classes work on their own.

Compared with stock Bootstrap. Stock Bootstrap has no .bg-red palette family, .bg-default, .bg-muted, .border-default, .border-muted or .text-default, and does not restyle .text-muted; its contextual .text-* and .border-* utilities use Bootstrap's own colours, while Redmaterials adds the extra utilities and the Material palette.

Background colours

Use .bg-{colour} for any of the 19 palette colours, plus .bg-default and .bg-muted for neutral fills.

.bg-muted

.bg-default is the palette neutral (#f8f8f8); .bg-muted is the contextual muted colour (#9E9E9E). They are fills, so they keep the same value in light and dark mode.

Contextual backgrounds

Bootstrap's contextual background utilities are restyled with the Material palette. Pair each fill with a text utility that stays legible on it, and add .border to .bg-white so the box keeps an edge on a light surface.

.bg-primary with .text-white
.bg-secondary with .text-white
.bg-dark with .text-white
.bg-light with .text-dark
.bg-white with .text-dark and .border

Contextual text colours

The contextual text utilities are shown on .bg-body, the page surface, so you can compare them against the background they actually sit on.

.text-primary — primary text

.text-secondary — secondary text

.text-success — success text

.text-info — info text

.text-warning — warning text

.text-danger — danger text

.text-muted — muted text

.text-primary … .text-danger follow the --rdm-text-* tokens and are lifted in dark mode; .text-muted is restyled to the Material grey (#9E9E9E).

Fixed text colours

.text-default, .text-light and .text-white are light values and .text-dark is dark, so each is shown on .bg-body inside the colour mode where it stays readable.

.text-default — default text

.text-light — light text

.text-white — white text

.text-dark — dark text

These are fixed utility values, not tokens: they do not change with the page's colour mode and they do not honour --bs-text-opacity.

Text opacity

The token-driven .text-primary … .text-danger utilities use rgba(var(--rdm-text-<name>-rgb), var(--bs-text-opacity, 1)), so Bootstrap's .text-opacity-* utilities work on them.

Primary text at .text-opacity-100

Primary text at .text-opacity-75

Primary text at .text-opacity-50

Primary text at .text-opacity-25

.text-default, .text-muted, .text-light, .text-dark and .text-white set a fixed colour and ignore the opacity utilities.
