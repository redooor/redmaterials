Modals

Redmaterials keeps Bootstrap's modal markup and restyles the dialog: a translucent Material surface, 2px corners, no border between the header, body and footer, and the deepest theme shadow on .modal-content from 768px up. Bootstrap's bundle JavaScript drives it through data-bs-toggle="modal" and data-bs-target; Redmaterials adds no script and no data attribute.

Compared with stock Bootstrap. Stock Bootstrap's dialog uses an opaque --bs-body-bg surface, 0.5rem corners and 1px header and footer borders, with its lighter default shadow; Redmaterials gives it a translucent Material surface, 2px corners, no border between the header, body and footer, and the deepest theme shadow on .modal-content from 768px up. The markup and every data-bs-* option are Bootstrap 5.

Header, footer and depth

The preview is the same dialog laid out inline with .position-static and .d-block, so the borderless header and footer and the depth shadow are visible without opening anything; the footer here uses text so the preview has no dead controls.
