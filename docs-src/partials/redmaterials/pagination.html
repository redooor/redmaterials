Pagination

Redmaterials keeps Bootstrap's pagination markup and gives the page links a Material treatment: borderless cells with 2px corners, roomier 0.8em 1.5em padding, the Material primary for the active page and a soft focus ring. No data attribute or JavaScript is needed.

Bootstrap vs Redmaterials. In Bootstrap mode the page links return to Bootstrap's 1px border, 0.375rem corners, 0.375rem 0.75rem padding and default blue active page. The .pagination, .page-item, .page-link and size classes are Bootstrap 5 throughout.

Overview

Wrap the list in a nav with an aria-label, mark the current page with .active and aria-current="page", and add .flex-wrap so long pagers wrap on narrow screens.

Active and disabled states

Use .active with aria-current="page" for the current page and .disabled with aria-disabled="true" plus tabindex="-1" for an unavailable control; the theme keeps the disabled background but mutes the label.
