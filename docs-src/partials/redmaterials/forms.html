Forms

Redmaterials restyles Bootstrap's form controls instead of adding new classes: text inputs and textareas lose their box and get a 1px underline that thickens and turns primary on focus; selects keep an arrow; checks, radios, switches, the range and input-group addons all follow the Material treatment. No data attribute or JavaScript is needed, and validation uses Bootstrap's .is-valid and .is-invalid classes.

Compared with stock Bootstrap. Stock Bootstrap gives every control its default styling: boxed inputs with rounded borders, the default blue focus ring and Bootstrap's own check, switch and range colours; Redmaterials removes the box for a 1px underline that thickens and turns primary on focus, keeps the select arrow, and restyles checks, radios, switches, the range and input-group addons. The markup and the .form-label, .form-check, .form-switch, .form-range and validation classes are Bootstrap 5 throughout.

Text inputs

Use Bootstrap's .form-control with a .form-label; the theme removes the border and draws a single underline instead.

Selects

.form-select keeps Bootstrap's arrow but drops its box for the same underline; a plain <select> gets the theme's own arrow from the stylesheet.

Checks and radios

Keep Bootstrap's .form-check markup: the theme squares the checkbox, rounds the radio and paints both with the Material primary when checked.

Switches

A .form-check.form-switch keeps the native checkbox but restyles it as a track and thumb; give the input role="switch" for assistive technology.

Range

.form-range uses the theme primary for the thumb and a translucent primary for the track; label it like any other control.

File input

Bootstrap's file input keeps its button, and the field underneath takes the theme's underline like a text input.

Input groups

Add text or a button with .input-group; the theme gives the addon the same underline as the field instead of a separate box.
