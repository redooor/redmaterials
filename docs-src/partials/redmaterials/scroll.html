Scroll lock

rdm-ui-disable-scroll is a runtime state class, not markup to author: js/redmaterials.js adds it to <body> while the nav sidebar is open and removes it when the sidebar closes, and scss/scroll.scss gives that class overflow: hidden. The page therefore cannot scroll behind the open drawer, and normal scrolling returns on dismissal.

It is documented as code only because it never appears in static markup: adding it by hand would lock the page with no sidebar to close, and the class is excluded from the live-example audit for that reason.

Compared with stock Bootstrap. Bootstrap's offcanvas implements its own body scroll lock; rdm-ui-disable-scroll is a Redmaterials addition for the nav sidebar, and stock Bootstrap has no such class.

To see it, open the live demo in the Nav Sidebar section and inspect the body element while the drawer is open.
