Nav Sidebar

Redmaterials adds an off-canvas navigation sidebar that slides in from the left, or from the right with .nav-sidebar-right. It is hidden beyond the viewport until a trigger carrying data-toggle="nav-sidebar-toggle" and data-target="#wrapper-id" is clicked; the Redmaterials script then adds .active to the wrapper, shows the overlay and locks body scrolling with rdm-ui-disable-scroll. The live demo below opens the real fixed component over this page.

Bootstrap vs Redmaterials. The nav sidebar is a Redmaterials addition, not a Bootstrap component: in Bootstrap mode these classes have no styling or behaviour, so the previews below render as unstyled lists. Use Bootstrap's own offcanvas for a stock Bootstrap drawer.

Default sidebar

A .nav-sidebar is normally position: fixed, so this preview places it inline with .position-relative, .start-0 and .h-auto; the title bar and active row use the neutral .nav-sidebar-default variant.

Markup and behaviour

Wrap the sidebar and its overlay in a .nav-sidebar-wrapper with a unique id, then point any trigger at that id. The Redmaterials script toggles .active on the wrapper; the CSS slides .nav-sidebar into view, displays .nav-sidebar-overlay and adds rdm-ui-disable-scroll to <body> while it is open.

The trigger carries both attributes; it can be a button, a link or the overlay itself. Give the trigger an accessible name because it opens a navigation region.

The overlay is the dimmed backdrop. It uses the same toggle attributes, so a click outside the sidebar dismisses it; the JavaScript also handles data-bs-target as a fallback for markup written with Bootstrap's attribute name. Bootstrap's bundle JavaScript is not used by this component, but the page still needs Bootstrap's JavaScript for its other components.
