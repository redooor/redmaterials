Progress

Redmaterials keeps Bootstrap's .progress and .progress-bar markup and restyles the bar in scss/progress-bars.scss: 6px tall, square ends, no track shadow, and the Material brand primary as the default fill. Set the value with an inline width and describe it with role="progressbar" plus aria-valuenow, aria-valuemin, aria-valuemax and aria-label on the outer .progress. No data attribute or JavaScript is needed.

Bootstrap vs Redmaterials. In Bootstrap mode the track returns to 1rem tall with 0.375rem rounded ends and the inset track shadow, and the default fill returns to Bootstrap blue. The contextual .bg-*, striped and animated classes are Bootstrap 5 throughout.

Card with progress

There is no Redmaterials "card with progress" wrapper class: this is the stock .progress placed directly between .card-header and .card-body, and it inherits the same 6px square-ended bar. The .card supplies the surface and radius; add a .shadow-depth-* class when the card should sit above the page.
