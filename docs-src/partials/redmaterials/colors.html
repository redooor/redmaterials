Colours

Redmaterials adds the 19 Google Material Design palette colours as background utilities, alongside Bootstrap's contextual colours and a small set of light/dark design tokens. No data attribute or JavaScript is required: the utility class alone enables a swatch.

Bootstrap vs Redmaterials. In Bootstrap mode the .bg-red … .bg-blue-grey palette utilities do not exist, so the swatches below lose their fill; the contextual .bg-primary family falls back to Bootstrap's own colours, while Redmaterials maps it to the Material brand.

Palette swatches

Every Material palette colour is available as .bg-{colour}; the utility name is printed below each swatch.

Brand variables

The brand colours are Sass variables declared with !default in scss/variables.scss; they feed both the contextual utilities and Bootstrap's --bs-* theme variables. $brand-primary defaults to the 700 shade of blue so that links and buttons reach 4.6:1 on white.

Customising the brand

The supported customisation is Sass: load variables with your own values first, then load redmaterials, and compile with the Sass CLI.

@use "variables" with ( $brand-primary: #e91e63, $brand-secondary: #455a64 ); @use "redmaterials";

Compile the file with Redmaterials' scss directory on the load path; changing a brand variable updates Bootstrap's --bs-* vars, the contextual utilities and the components that derive from them in one pass.

sass --load-path=path/to/redmaterials/scss theme.scss theme.css

Dark mode

Neutral tokens follow the data-bs-theme attribute: surfaces, text, dividers, control chrome, interaction washes and shadows switch to their dark values. Brand and palette fills such as .bg-red or .bg-primary are identity colours and stay the same in both modes. When a brand colour is used as text—.text-primary, .link-primary or a flat button—the --rdm-text-* and --rdm-pal-* tokens lift it towards white until it reaches 4.5:1 on the dark surface, with hover states that stay lighter than the base. The derived --bs-*-bg-subtle and --bs-*-border-subtle values are light-only, so Bootstrap's own dark values remain in force.
