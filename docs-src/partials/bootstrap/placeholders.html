Placeholders

Build loading skeletons from lightweight placeholder spans, sized and coloured with Bootstrap utilities and animated while content arrives.

Card with placeholders

Compose a card skeleton from placeholder spans in the title, text, and button positions.

Widths

Set placeholder widths with the grid .col-* classes or the .w-* utilities.

Colour

Change the placeholder colour with a .bg-* utility.

Sizing

Use .placeholder-lg, .placeholder-sm, or .placeholder-xs to change the height of a placeholder.

Animation

Add .placeholder-glow for a soft pulse or .placeholder-wave for a moving shine.

Buttons

Use a placeholder inside a disabled button, or as the whole disabled button, to reserve an action's space while it loads.
