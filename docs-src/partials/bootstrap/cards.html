Sizing

Cards fill the width of their grid column by default, or you can set a width directly on the card with a sizing utility or a width value.

Full-width card

This card fills the width of its .col-sm-6 column.

Three-quarter width

The .w-75 utility narrows this card inside the same column.

Fixed width

A width value keeps this card at 18rem regardless of its container.
