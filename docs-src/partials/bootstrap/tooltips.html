Tooltips

Tooltips add a short, contextual hint to a control on hover or focus, with configurable placement, triggers, and HTML content.

Live demo

Hover or focus the button to show a tooltip; tooltips are opt-in and need JavaScript initialisation.

Four directions

Set data-bs-placement to top, right, bottom, or left to control where the tooltip appears.

Click trigger

Set data-bs-trigger="click" when the tooltip should toggle from a click instead of hover or focus.

On links

Add a tooltip to a link when its destination needs extra context beyond the link text.

Read the release notes

Disabled elements

Wrap a disabled button in a focusable element so the tooltip can still receive pointer and keyboard events.

HTML content

Add data-bs-html="true" to render formatted content inside the tooltip; Bootstrap's sanitizer keeps the markup safe.
