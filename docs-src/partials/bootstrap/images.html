Images & figures

Bootstrap's image helpers keep media responsive, shaped, aligned, and captioned without extra CSS.

Responsive images

Add .img-fluid so an image scales with its parent instead of overflowing it.

The image scales down to fit narrow screens while keeping its natural aspect ratio.

Thumbnails

Add .img-thumbnail for a padded border around an image.

Rounded images

Use .rounded, .rounded-3, or .rounded-circle to soften an image's corners.

Image alignment

Float images beside text, center them as block elements, or align them with the text utilities.

This image floats to the start of the paragraph with .float-start, and the surrounding text wraps beside it. The clearfix keeps the following content below the float.

This image floats to the end of the paragraph with .float-end. On narrow screens the text still wraps around the image.

Centered with .text-center.

Figures

Use .figure, .figure-img, and .figure-caption to pair an image with a caption.

Picture element

A picture element can serve a wider image on larger screens while the img provides the fallback.

Aspect ratios

Use the preset .ratio-* classes to keep media in a fixed proportion as the container resizes.
