Accordion

Accordions stack collapsible panels behind a single set of headers, with optional auto-collapse, flush styling, and independent panels.

Default

Each panel pairs an h2.accordion-header button with an .accordion-collapse body, and data-bs-parent keeps only one panel open at a time.
