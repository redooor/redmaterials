Tables

Bootstrap's table classes add striping, borders, hover states, contextual colours, and responsive scrolling to plain HTML tables.

Striped rows

Add .table-striped for zebra-striped rows, or .table-striped-columns to stripe the columns instead.

Vertical alignment

Use .align-top, .align-middle, or .align-bottom on cells to control their vertical position in a taller row.

Alignment Heading Heading Heading
