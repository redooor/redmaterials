Carousel

A carousel cycles through slides with optional controls, indicators, captions, and theme variants, all driven by Bootstrap's data attributes.

Slides only

Add .carousel and .slide to a wrapper and mark one .carousel-item as .active; without a ride attribute the example stays on its first slide.

With controls

Add previous and next buttons with data-bs-target and data-bs-slide; each icon-only control needs a .visually-hidden label.

With indicators

Add a list of indicator buttons after the slides, with data-bs-target, data-bs-slide-to, and an aria-label for each one.

With captions

Place a .carousel-caption inside a slide to add a heading and supporting text; the caption is hidden on small screens so it never crowds the image.

Crossfade

Add .carousel-fade to crossfade between slides instead of sliding them horizontally.

Individual interval

Set data-bs-interval on a carousel to change its delay when automatic cycling is enabled; this documentation example omits data-bs-ride, so it stays put until you use the controls.

Disable touch swiping

Add data-bs-touch="false" to stop touch devices from swiping between slides, leaving the visible controls as the only way to move.

Dark variant

Add data-bs-theme="dark" to the carousel for dark captions and controls, then use lighter slides so the text keeps its contrast.
