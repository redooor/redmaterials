Offcanvas

Offcanvas builds a hidden side panel from a trigger, with options for scrolling, backdrop, colour scheme, responsive behaviour, and placement.

Live demo

Launch an offcanvas panel from a button; the panel slides in from the start edge and closes from its header or the backdrop.

Static backdrop

Dark offcanvas

Add data-bs-theme="dark" to the panel so its surface, text, and close button use Bootstrap's dark colour scheme.

Dark offcanvas

Bootstrap's dark theme variables recolour the panel without any custom CSS.

Responsive

Use .offcanvas-lg so the panel behaves as an inline block on large screens and as an offcanvas panel below the large breakpoint.

Responsive offcanvas

On large screens this content is laid out in the page; on smaller screens it slides in from the end edge.
