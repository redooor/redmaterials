Forms

Bootstrap's form controls, layout helpers, and validation states build accessible forms for every input type.

Form controls

Use .form-control on text inputs and textareas, with a label tied to each control's id.

We'll never share your email with anyone else.

Readonly and plaintext

A readonly input keeps its form styling, while .form-control-plaintext renders the value as plain text.

File and colour inputs

File inputs use .form-control, and .form-control-color sizes a native colour picker to its swatch.

Sizing

Add .form-control-lg or .form-control-sm to match an input's height to its context.

Selects

Use .form-select for single and multiple selects, with .form-select-lg or .form-select-sm for sizing.

Checks and radios

Use .form-check for checkboxes and radios, with .form-check-inline or the disabled attribute as needed.

Toggle buttons

Pair a .btn-check input with a label styled as a button to build checkbox and radio button groups.

Switches

Add .form-switch to a checkbox to render it as a toggle switch.

Range

Use .form-range for a native range slider, with an optional disabled state.

Datalist

Connect an input to a datalist with its list attribute to offer suggested values.

Floating labels

Wrap a control and its label in .form-floating to float the label when the field is focused or filled; it also works with selects, textareas, and grid columns.

Grid layout

Place form controls in grid columns to build multi-column forms that collapse on smaller screens.

Horizontal form

Use grid classes and .col-form-label to align labels beside their controls.

Inline form

The .row-cols-lg-auto layout keeps controls inline on large screens and stacks them on small ones.
