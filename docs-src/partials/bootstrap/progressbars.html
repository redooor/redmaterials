Progress

Show task completion with progress bars that support labels, custom heights, contextual backgrounds, stacking, and stripes.

Basic

Set the bar width with a percentage and describe the value with aria-valuenow, aria-valuemin, aria-valuemax, and an accessible name.

Multiple bars

Place several bars inside one .progress to show the parts of a total, giving each bar its own accessible name.

Striped

Add .progress-bar-striped to apply a striped background to any progress bar.

Animated stripes

Add .progress-bar-animated to animate the stripes from left to right.
