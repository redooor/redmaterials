Collapse

Collapse toggles the visibility of content with a smooth height or width transition, driven by data attributes and accessible trigger controls.

Basic

Use a link or button with data-bs-toggle="collapse" and a target that points at a .collapse element.

Some placeholder content for the collapse component. This panel is hidden by default and revealed when a trigger is activated.

Horizontal

Add .collapse-horizontal to transition the width instead of the height, and give the child an explicit width.

This content collapses horizontally. The card keeps a fixed width so the transition has a clear target size.

Multiple targets

Point data-bs-target at a class to toggle several collapsible elements at once, or give each toggle its own target.
