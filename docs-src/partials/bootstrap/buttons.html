Buttons

Bootstrap's button classes provide consistent colours, sizes, states, and toggle behaviour for actions and links.

Variants

Use a contextual .btn-* class for the eight theme colours, or .btn-link for a button that looks like a link.

Outline

Outline buttons use a transparent background and a coloured border, and fill with the matching colour on hover.

Sizes

Add .btn-lg or .btn-sm to change a button's font size and padding.

Disabled state

Use the disabled attribute on a button, or .disabled and aria-disabled="true" on a link, to prevent interaction.

Block buttons

Wrap buttons in .d-grid with a gap utility to stack them at full width.

Button tags

The button classes work on a, button, and input elements; use the matching element for the action.

Link

Toggle states

Add data-bs-toggle="button" to toggle a button's active state on click, or set .active and aria-pressed="true" for a static pressed state.

Checkbox and radio buttons

Pair .btn-check inputs with button labels to create checkbox and radio button groups that look like normal buttons.

Close button

Use .btn-close for a dismissible close control, and .btn-close-white on a dark surface.
