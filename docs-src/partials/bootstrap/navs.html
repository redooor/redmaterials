Tabs with dynamic panes

Pair each data-bs-toggle="tab" control with a matching pane and Bootstrap switches the .active and .show classes for you.

The home pane is active when the page loads, and each tab swaps in its own pane.

The profile pane appears when the Profile tab is selected, with a short fade transition.

The contact pane completes the set and can hold any content.

Pills with dynamic panes

The same tab behaviour works with pills; change the toggle to data-bs-toggle="pill" and keep the matching pane ids.

The overview pane introduces the component.

The usage pane shows how the pills are marked up.

The settings pane covers the available modifiers.
