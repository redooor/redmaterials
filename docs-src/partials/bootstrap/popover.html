Popovers

Popovers attach a larger overlay to an element, with a title, body content, configurable placement and container, and either click or focus-based dismissal.

Live demo

Click the button to toggle a popover with a title and a short body.

Four directions

Set data-bs-placement to top, right, bottom, or left to control where the popover appears.

Custom container

Set data-bs-container to a selector so the popover is appended inside that element instead of the document body.

This popover is appended to the bordered container rather than the body.

Dismissible

Use data-bs-trigger="focus" so the popover closes when the user clicks elsewhere or presses Escape.

Disabled elements

Wrap a disabled button in a focusable element so the popover can still receive pointer and keyboard events.

HTML content

Add data-bs-html="true" to render HTML inside the popover; Bootstrap's sanitizer keeps the markup safe.

Initialisation

Enable every popover trigger on the page with the JavaScript initialiser below.

document.querySelectorAll('[data-bs-toggle="popover"]').forEach(function (el) { new bootstrap.Popover(el); });
