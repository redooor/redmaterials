Redmaterials by Redooor

Bootstrap theme inspired by Google Material Design and various projects

This is a consolidation of many works by various people. Please refer to README.md Acknowledgement section for more information.

Refer to CHANGE LOG for the changes made to the latest release.

Note to users

Version 0.1.0 is an incomplete release. We're constantly adding new features to Redmaterials. We appreciate your patience and welcome all contributions. Meanwhile, do expect that some things (specifically those elements that are not inherited from Bootstrap) are not confirmed and may be removed from future releases. We'll try as much as possible to retain the components inherited from Bootstrap.

Important Note

From version 0.0.3, we will not import Roboto font within Redmaterials CSS file. To use it, you need to separately add a link in your header.

Add this to your header:

<link href='https://fonts.googleapis.com/css?family=Roboto' rel='stylesheet' type='text/css'>

Alternatively, you may use Web Font Loader to dynamically load Roboto font.

For example:

<script src="https://cdnjs.cloudflare.com/ajax/libs/webfont/1.6.26/webfontloader.js"></script>
<script>
  WebFont.load({
    google: {
      families: ['Roboto']
    }
  });
</script>

Wrap the sidebar with a div class nav-sidebar-wrapper and give it a unque ID.

<div id="nav_sidebar_demo1" class="nav-sidebar-wrapper">

Within the wrapper, you need 2 divs, nav-sidebar and nav-sidebar-overlay :

nav-sidebar contains the menu list nav nav-sidebar-menu. By default it's hidden from view.

<div class="nav-sidebar nav-sidebar-default shadow-depth-1">
    <div class="nav-sidebar-title">
        <a href="#top" class="nav-sidebar-brand">Nav Sidebar</a>
    </div>
    <ul class="nav flex-column nav-sidebar-menu">
        <li class="nav-sub-header"><span>Header 1</span></li>
        <li><a href="#">Test 1</a></li>
        <li><a href="#">Test 2</a></li>
        <li class="active"><a href="#">Active 3</a></li>
        <li><a href="#">Test 4</a></li>
        <li role="separator" class="divider"></li>
        <li class="nav-sub-header"><span>Header 2</span></li>
        <li><a href="#">Test 5</a></li>
        <li><a href="#">Test 6</a></li>
        <li><a href="#">Test 7</a></li>
        <li><a href="#">Test 8</a></li>
    </ul>
</div>

nav-sidebar-overlay is the overlay when the sidebar is shown to prevent main body from scrolling.

<div class="nav-sidebar-overlay" data-toggle="nav-sidebar-toggle" data-target="#nav_sidebar_demo1"></div>

To toggle the sidebar on/off, simply add the

data-toggle="nav-sidebar-toggle"

and

data-target="#your_wrapper_id"

to any element, such as button and overlay. data-target should contain your wrapper's ID.

I had given the nav-sidebar-overlay those properties so that user can click the overlay to dismiss the sidebar.

Full example code:

<div id="nav_sidebar_demo1" class="nav-sidebar-wrapper">
    <div class="nav-sidebar nav-sidebar-default shadow-depth-1">
        <div class="nav-sidebar-title">
            <a href="#top" class="nav-sidebar-brand">Nav Sidebar</a>
        </div>
        <ul class="nav flex-column nav-sidebar-menu">
            <li class="nav-sub-header"><span>Header 1</span></li>
            <li><a href="#">Test 1</a></li>
            <li><a href="#">Test 2</a></li>
            <li class="active"><a href="#">Active 3</a></li>
            <li><a href="#">Test 4</a></li>
            <li role="separator" class="divider"></li>
            <li class="nav-sub-header"><span>Header 2</span></li>
            <li><a href="#">Test 5</a></li>
            <li><a href="#">Test 6</a></li>
            <li><a href="#">Test 7</a></li>
            <li><a href="#">Test 8</a></li>
        </ul>
    </div>
    <div class="nav-sidebar-overlay" data-toggle="nav-sidebar-toggle" data-target="#nav_sidebar_demo1"></div>
</div>

Right Sidebar

By default the sidebar sticks to the left of the screen.

If you want the sidebar to stick to the right instead, add class:

nav-sidebar-right

Like this:

<div class="nav-sidebar nav-sidebar-default nav-sidebar-right shadow-depth-1">
