Redmaterials by Redooor

A Bootstrap 5.3 theme inspired by Google Material Design. Version 0.2.0.

Redmaterials restyles Bootstrap's components with a Material look and adds a few of its own: a navigation sidebar, corner ribbons, the ripple effect, shadow depths and wells. This site shows every component twice: under Bootstrap and under Redmaterials. Use the Bootstrap | Redmaterials switch in the sidebar to see the same example with and without the theme.

Redmaterials is a consolidation of many works by various people; see the acknowledgements. Source code and issues are on GitHub.

Install

Copy dist/css and dist/js to your project and use redmaterials.min.css and redmaterials.min.js. Redmaterials requires Bootstrap 5.3.x and must be loaded after Bootstrap. Use Bootstrap's bundle JavaScript, which includes Popper. Neither Bootstrap 5 nor Redmaterials needs jQuery.

In your <head>:

<link href="https://fonts.googleapis.com/css?family=Roboto:300,400,500,700" rel="stylesheet">
<link href="https://fonts.googleapis.com/icon?family=Material+Icons" rel="stylesheet">
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.8/dist/css/bootstrap.min.css">
<link rel="stylesheet" href="dist/css/redmaterials.min.css">

Before the closing </body>:

<script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.8/dist/js/bootstrap.bundle.min.js"></script>
<script src="dist/js/redmaterials.min.js"></script>

Roboto is not bundled with Redmaterials, so add the font link above (or load it with Web Font Loader). Material Icons is optional; it is used for the icons on this site.

Customising

The theme colours and sizes are Sass variables. Load the variables module with your values first, then Redmaterials, and compile with Sass (sass --load-path=path/to/redmaterials/scss theme.scss theme.css):

@use "variables" with ($brand-primary: #e91e63, $brand-secondary: #455a64);
@use "redmaterials";

Note to users

Components that Redmaterials inherits from Bootstrap are kept as close to Bootstrap as possible. The elements Redmaterials adds on top of Bootstrap (nav sidebar, corner ribbons, ripple effect, shadows, wells) are its own and may change in a future release. Contributions are welcome.
