Redmaterials by Redooor

A Bootstrap 5.3 theme inspired by Google Material Design. Version 0.2.0.

Redmaterials restyles Bootstrap's components with a Material look and adds a few of its own: a navigation sidebar, corner ribbons, the ripple effect, shadow depths and wells. This site shows every component twice: under Bootstrap and under Redmaterials. Use the Bootstrap | Redmaterials switch in the sidebar to see the same example with and without the theme.

Redmaterials is a consolidation of many works by various people; see the acknowledgements. Source code and issues are on GitHub.

Install

Copy dist/css and dist/js to your project and use redmaterials.min.css and redmaterials.min.js. Redmaterials requires Bootstrap 5.3.x and must be loaded after Bootstrap. Use Bootstrap's bundle JavaScript, which includes Popper. Neither Bootstrap 5 nor Redmaterials needs jQuery.

In your <head>:

<link href="https://fonts.googleapis.com/css?family=Roboto:300,400,500,700" rel="stylesheet">
<link href="https://fonts.googleapis.com/icon?family=Material+Icons" rel="stylesheet">
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.8/dist/css/bootstrap.min.css">
<link rel="stylesheet" href="dist/css/redmaterials.min.css">

Before the closing </body>:

<script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.8/dist/js/bootstrap.bundle.min.js"></script>
<script src="dist/js/redmaterials.min.js"></script>

Roboto is not bundled with Redmaterials, so add the font link above (or load it with Web Font Loader). Material Icons is optional; it is used for the icons on this site.

Customising

The theme colours and sizes are Sass variables. Load the variables module with your values first, then Redmaterials, and compile with Sass (sass --load-path=path/to/redmaterials/scss theme.scss theme.css):

@use "variables" with ($brand-primary: #e91e63, $brand-secondary: #455a64);
@use "redmaterials";

Note to users

Components that Redmaterials inherits from Bootstrap are kept as close to Bootstrap as possible. The elements Redmaterials adds on top of Bootstrap (nav sidebar, corner ribbons, ripple effect, shadows, wells) are its own and may change in a future release. Contributions are welcome.

Scrollspy

Scrollspy highlights the link that matches the section currently in view, both for this page's sidebar navigation and for any scrollable container you mark up yourself.

How this page uses it

The sidebar on this page is a live scrollspy: as you read, the current section's link is highlighted and kept in view, so you can always see where you are.

Nav in a scrollable container

Add data-bs-spy="scroll" and a data-bs-target pointing at a nav; links whose hashes match the section ids inside the container are activated as it scrolls.

Introduction Usage Options Events
Scrollable panel

This panel has its own scrollbar. The links on the left follow the section in view as you scroll, and clicking a link moves the panel to that section.

The linked sections start below this introduction, so no link is highlighted until the first one scrolls into view.

Introduction

Scrollspy watches a scroll container and compares the position of each section with the container's viewport. The matching navigation link receives the .active class.

It works on the page body by default, or on any element that has its own scrollbar when you add the spy attributes to that element.

Usage

Give every target section a unique id, then link to those ids from a nav or list group inside the same example. Keep the navigation close to the scrolling content so readers can move between the two.

Set data-bs-offset when a fixed header covers the top of the sections, and keep each section tall enough that only one is in view when a link is followed.

Options

The offset shifts the activation line, while the root margin and threshold tune how much of a section must be visible before it is chosen. The defaults suit most pages.

Use data-bs-target to scope the spy to one navigation list; without it, Scrollspy will look for links throughout the document.

Events

The component emits an activate event whenever the highlighted link changes. That event is useful for keeping a custom indicator or an offcanvas menu in step with the page.

Refresh the instance after adding or removing sections dynamically so the list of observed targets stays accurate.

Scrollspy also accepts a list group as its target, adding the active state to the matching list item as the reader moves through the content.

Overview Setup Caveats
Scrollable panel

This panel starts with an introduction that is not one of the list group's targets, so the list begins with no active item.

Scroll the panel or choose an item to bring its section into view; the matching list item then receives the active state.

Overview

A list group behaves like a nav for Scrollspy: each action item points at a section, and the active item follows the scroll position.

Keep the list and the content in the same container so the links stay within reach on small screens.

Setup

Add the spy attributes to the scrolling element and point data-bs-target at the list group. Section ids must match the link hashes exactly.

If a section is shorter than the activation threshold, combine it with a neighbour or lower the threshold until it can be selected reliably.

Caveats

Scrollspy observes sections, not links, so every link needs a real target with visible height. Hidden or empty sections are ignored.

When the container is not scrollable, the whole page becomes the scroll root and the active item changes with the page position instead.
